# Inventory Management System

Enterprise-grade system to manage procurement, inventory, suppliers, and production workflow.

## Tech Stack
- Java, Spring Boot, Spring Security, JWT
- Angular
- Oracle Database

## Features
- Role-Based Access Control (Admin, PO, IM, PM, Supplier)
- Secure JWT Authentication
- Order → Inventory → Production workflow
- Supplier & Raw Material Mapping

## How to Run
Backend:
mvn spring-boot:run

Frontend:
ng serve
